Maharashtra Saral Seva Bharti - GitHub Pages site
-----------------------------------------------
Files prepared for GitHub Pages. To publish:

1. Create a new GitHub repository (public).
2. Upload all files and folders from this package to the repository root.
3. In repo -> Settings -> Pages, choose branch 'main' (or 'master') and folder '/'.
4. Save; GitHub will publish at: https://<your-username>.github.io/<repo-name> within a minute.

Replace assets/logo.png with your real logo if needed.
Edit index.html and pages/*.html to add real posts and links.
